# 🌐 Google Clone

Um clone da página inicial do **Google**, desenvolvido como parte dos estudos de desenvolvimento front-end. O projeto replica a interface clássica de busca, incluindo o cabeçalho de navegação, o logotipo estilizado com as cores oficiais, a barra de pesquisa interativa com ícones e o rodapé completo.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando apenas tecnologias essenciais de estruturação e estilização:

* **HTML5**: Estruturação semântica da página (cabeçalho, container principal e rodapé).
* **CSS3**: Estilização completa do layout, cores oficiais da marca, alinhamentos e responsividade.
* **Google Fonts & Material Symbols**: Ícones modernos e tipografia padrão.

## ✨ Funcionalidades e Aprendizados

* **Layout Responsivo**: Ajuste fluido para diferentes tamanhos de tela (computadores, tablets e celulares) utilizando técnicas modernas de CSS como `Flexbox`, `max-width` e quebras flexíveis (`flex-wrap`).
* **Cores Oficiais**: Aplicação individual de cores estilizadas em cada letra do logotipo do Google.
* **Efeitos de Hover**: Interações visuais nos botões e links de navegação para simular o comportamento da página original.
